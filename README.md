# sbGame2
Making a board game about skateboarding with no boards. 

This is very much a work in progress, the bare bones are here. 

Basically, you pick a spot, you get a target score to beat. You roll the dice, if you roll more than the target, you gain a point. 

Eventually this will be a card-based game that can be played single or multiplayer on the page, or across the web.
